# Работа с библиотекой

- Общие исходники скиллов находятся в `skills/<skill-name>/SKILL.md`.
- Инструкции и код подключения находятся в `harnesses/<harness-name>/`.
- Общие CLI-инструменты находятся в `cli/<tool-name>/`; реальные секреты и
  персональные настройки хранятся вне библиотеки.
- MCP-серверы и контейнеры находятся в `mcp/<server-name>/`.
- Не смешивай инструкции выполнения задачи с установкой в конкретный харнесс.
- Создавай скиллы под конкретные задачи; не добавляй пустые заготовки
  для предполагаемых будущих возможностей.
- Сохраняй самостоятельность скилла: относительные ссылки на его ресурсы,
  явные зависимости, отсутствие привязки к машине автора.
- Перед изменением адаптера проверяй формат подключения по официальной
  документации соответствующего харнесса.
- Проверяй изменённые скрипты и ссылки на ресурсы. Не заявляй совместимость
  с харнессом, если подключение в нём не проверено; отмечай эту границу в README.
