# Подключение к Codex

Исходники остаются в `skills/`. Адаптер создаёт ссылки на все найденные папки
с `SKILL.md`, включая вложенные категории, в выбранном каталоге обнаружения.
Изменения исходников доступны через те же ссылки.

Согласно [документации Codex](https://learn.chatgpt.com/docs/build-skills),
пользовательские скиллы читаются из `~/.agents/skills`, проектные — из
`.agents/skills`; ссылки на папки поддерживаются.

Запускай из корня библиотеки. Сначала можно посмотреть план:

```bash
python3 harnesses/codex/connect.py install --target ~/.agents/skills --dry-run
python3 harnesses/codex/connect.py install --target ~/.agents/skills
python3 harnesses/codex/connect.py check --target ~/.agents/skills
```

Обновление инструкции не требует повторного копирования. После добавления
нового скилла повтори `install`. При переименовании сначала удали старые
подключения через `remove`, затем переименуй исходники и выполни `install`. Повторная установка не создаёт дубликаты,
существующие чужие файлы и ссылки вызывают ошибку без перезаписи.

Удаление подключения:

```bash
python3 harnesses/codex/connect.py remove --target ~/.agents/skills --dry-run
python3 harnesses/codex/connect.py remove --target ~/.agents/skills
```

Удаляются только ссылки, ведущие на текущие исходники библиотеки.
Перед перемещением библиотеки удали подключения, затем установи их заново.

Явный вызов: `$youtube-idea-development`, `$youtube-channel-strategy`, `$youtube-title-thumbnail`,
`$youtube-script-development`, `$youtube-performance-review` плюс описание задачи.
Если скиллы не появились в выборе после установки, перезапусти Codex.

Проверено: создание и чтение ссылок для пяти скиллов, повторная установка
и отсутствие перезаписи конфликтующего файла. Обнаружение через интерфейс
Codex и выполнение каждого скилла отдельно не тестировались.
Шаг записи в Notion требует авторизованного MCP Notion в целевом окружении.

## Контекст YouTube-канала

Открывай отдельную папку канала как проект Codex. В её `AGENTS.md` укажи,
где находятся профиль канала, индекс выпусков, прошлые сценарии и выводы
из аналитики, а также какие источники считаются основными. Это могут быть
относительные пути к файлам или ссылки на внешние документы. Скиллы читают
относящиеся к задаче материалы по этой карте; личные данные канала остаются
вне библиотеки. Доступ к закрытым внешним документам нужно предоставить
отдельно через подключение либо экспорт.
