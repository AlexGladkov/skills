# Библиотека скиллов

Общие скиллы хранятся отдельно от способов подключения к агентным харнессам.
Этот репозиторий — источник исходников; подключение выполняется отдельно для
выбранного харнесса и проекта.

```text
skills/
  <skill-name>/
    SKILL.md
    references/       # при необходимости
    scripts/          # при необходимости
    assets/           # при необходимости
harnesses/
  <harness-name>/
    README.md         # поддерживаемые версии и способ подключения
    scripts/          # если подключение требует автоматизации
    templates/        # если нужны конфиги или файлы инструкций
cli/
  <tool-name>/        # инструменты, вызываемые из разных харнессов
mcp/
  <server-name>/      # MCP-серверы и их контейнеры
```

## Скиллы

Каждый скилл — самостоятельная папка в `skills/`. Название папки совпадает
с `name` в `SKILL.md`: строчные латинские буквы, цифры и дефисы.
В начале `SKILL.md` обязательны поля YAML `name` и `description`.

```markdown
---
name: investigate-bug
description: Найти причину воспроизводимой ошибки и проверить исправление.
---

Здесь находятся инструкции, которые помогают выполнить конкретную задачу.
```

Создавай скиллы под конкретные повторяющиеся задачи. Добавляй вспомогательные
папки только тогда, когда они нужны. Детальные справочные материалы выноси
в `references/` и связывай с инструкциями в `SKILL.md`.

В общих инструкциях не закрепляй домашние пути, названия инструментов,
доступных только в одном харнессе, или требования его конфигурации.
Зависимости скилла описывай явно. Если ему нужен определённый инструмент,
адаптер должен объяснять, как предоставить этот инструмент или ограничить
использование скилла.

## Подключения

Для каждого харнесса создавай отдельную папку в `harnesses/`.
Правила её наполнения находятся в [harnesses/README.md](harnesses/README.md).
Оригиналы скиллов остаются в `skills/`; копии, ссылки и преобразованные
инструкции в целевом окружении — результат подключения.

Подключение к Codex описано в [harnesses/codex/README.md](harnesses/codex/README.md).

## CLI-инструменты

[nasctl](cli/nasctl/README.md) предоставляет ограниченные операции с фильмами
через Radarr. Инструмент хранится отдельно от скиллов и адаптеров харнессов.
Защищённая установка в ОС выполняется отдельно; секретов в библиотеке нет.

## MCP-серверы

[NAS MCP](mcp/nas/README.md) запускается на NAS в Docker и предоставляет
ограниченные операции Radarr. Подключение клиентов описывается отдельно
в `harnesses/`. Секреты и персональные настройки хранятся вне библиотеки.
